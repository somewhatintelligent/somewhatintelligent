# Design

artwork can accumulate without weighing the documentation down.

- [`somewhatintelligent/`](./somewhatintelligent/) — brand direction, shirt
  artwork and print files, campaign and concept studies, product-page mockups,
  and the brand study that the interface and email chrome cite.

Code that implements the design system lives in `packages/platform.design`;
this directory is the source material it was built from.
